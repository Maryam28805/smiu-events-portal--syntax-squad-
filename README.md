# SMIU Events Portal

## Project Overview
SMIU Events Portal is a responsive website designed to display university events, societies, event details, and registration information.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5.3.3

## Project Pages
- Home Page (index.html)
- Events Page (events.html)
- Event Details Page (event-details.html)
- Societies Page (societies.html)
- Registration Page (register.html)
- Contact Page (contact.html)

## How to Run
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.

## Team Contributions
Each team member contributed to assigned pages and collaborated through GitHub branches, commits, pull requests, and reviews.

## Testing
The Contact Page was tested in the browser for layout, navigation, and responsiveness.
